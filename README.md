# 📊 HR Analytics – Recruitment & Training Analysis

## 📌 Project Overview

This project focuses on Human Resource Analytics using Microsoft Excel to analyze recruitment, employee training, learning improvement, and training effectiveness.

The project helps HR professionals understand recruitment efficiency, hiring costs, candidate selection, employee learning progress, and training outcomes through data analysis.

## 🎯 Objectives

* Analyze recruitment efficiency and time to fill vacancies.
* Evaluate recruitment costs and cost per hire.
* Identify effective recruitment sources.
* Calculate offer acceptance rates.
* Analyze employee training costs.
* Measure learning improvement through pre-test and post-test scores.
* Evaluate training effectiveness using employee performance and attendance data.

## 📈 Project Exercises

### Exercise 1: Time to Fill

Analyzes the number of days required to fill recruitment vacancies and evaluates recruitment efficiency.

### Exercise 2: Cost per Hire

Evaluates recruitment expenses and calculates the cost associated with hiring employees.

### Exercise 3: Recruitment Source Analysis

Analyzes recruitment sources to understand candidate sourcing and recruitment channel effectiveness.

### Exercise 4: Offer Acceptance Rate

Measures the percentage of job offers accepted by candidates.

### Exercise 5: Training Cost Analysis

Analyzes employee training expenses and training-related costs.

### Exercise 6: Learning Improvement

Measures employee learning improvement by comparing pre-test and post-test scores.

### Exercise 7: Training Effectiveness

Evaluates training effectiveness using employee training ratings, attendance, and performance-related information.
